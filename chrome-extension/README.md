# 老虎快跑 Chrome 扩展

这个扩展只负责控制 Chrome 自己的代理设置，不直接读取请求内容。开启后，Chrome 的 HTTP/HTTPS 流量会被转发到老虎快跑桌面程序，抓包数据会出现在老虎快跑后台列表里。

## 安装

1. 打开 Chrome `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`chrome-extension`。

## 使用

1. 先启动老虎快跑桌面程序。
2. 确认代理端口是 `8080`。
3. 点击 Chrome 工具栏里的老虎快跑扩展。
4. 代理地址填 `127.0.0.1`，端口填 `8080`。
5. 点击“开启 Chrome 代理”。
6. 访问网页后，在老虎快跑桌面后台查看请求列表。

HTTPS 明文需要在 Windows 中信任老虎快跑根证书。可以在扩展里点击“打开证书页”，或在桌面程序中点击“安装到 Windows”。

## 和上游代理一起使用

Chrome 扩展里仍然填老虎快跑：

```text
127.0.0.1:8080
```

然后在老虎快跑桌面左侧“上游代理”里填上游代理地址：

```text
http://127.0.0.1:7890
```

最终链路是：

```text
Chrome -> 老虎快跑 -> 上游代理 -> Internet
```

这样 Chrome 只需要一个代理设置，老虎快跑可以抓包，上游代理继续负责后续连接。

## 说明

- 扩展使用 Chrome `proxy` 权限设置浏览器代理。
- 只影响 Chrome，不修改 Windows 系统代理。
- 关闭扩展代理后，会清除本扩展写入的 Chrome 代理设置。
- 如果其他代理扩展正在控制 Chrome 代理，本扩展会显示不可控制。
- SSL Pinning、私有加密协议、mTLS 等场景仍然可能无法解密 HTTPS 明文。
